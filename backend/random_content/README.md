# Random Content Packs

This folder stores the random-fill content used by `/api/random_sample`.

Design goals:
- Keep the prompt/lyrics building blocks editable without touching Python code.
- Allow finer-grained random combinations (genre/mood/instruments/structure).

Files:
- `prompt_parts.v1.json`: prompt building blocks and templates
- `lyrics_templates.v1.json`: lyrics templates and placeholder vocabularies
